======================================================================
  Knowledge Graph Builder
======================================================================

Author: Maharshi Soni
Category: knowledge-graph
Difficulty: advanced

----------------------------------------------------------------------
DESCRIPTION
----------------------------------------------------------------------
Extracts entities and relationships from text using NLP, builds queryable knowledge graph with NetworkX. Shortest path, PageRank, connected components. FastAPI REST API.

----------------------------------------------------------------------
TECH STACK
----------------------------------------------------------------------
  - networkx
  - nltk
  - fastapi
  - uvicorn
  - pydantic
  - numpy
  - httpx
  - pytest

----------------------------------------------------------------------
FEATURES
----------------------------------------------------------------------
  * NLP entity extraction
  * Relationship extraction
  * NetworkX graph
  * Graph queries: shortest path, PageRank
  * FastAPI REST API
  * Bulk ingestion

----------------------------------------------------------------------
SAMPLE INPUT
----------------------------------------------------------------------
  Text documents

  Example:
    curl -X POST /ingest -d '{"text": "John works at Google"}'

----------------------------------------------------------------------
SAMPLE OUTPUT
----------------------------------------------------------------------
  Graph query results

  Example:
    {"path": ["John", "works_at", "Google"], "entities": 45}
